# Leet/NeetCode automation script

Apart of my new years resolution I decided to start leetcoding every single this means that I open these tabs every single day. Just as a fun way for me to automate opening this I decided to make a script that I can call via macos shortcuts to open these webpages instantly.  

# How to run 

Edit the script to add/remove your own links needed to open.
Then put the script into a directory

```bash
cd your-directory
chmod +x general-leetcode-open.sh
```

Then if on mac os you can use ShortCut to map this script to a key bidning making it easier to open these tabs quickly.
